## 推荐学习顺序

### 1. 测试设计

先掌握等价类、边界值、判定表、场景法、正交组合、缺陷生命周期和测试报告。自动化脚本只是执行手段，不能替代测试分析。

### 2. Python 与 pytest

重点学习函数、列表/字典、异常、模块、类型标注、fixture、参数化、marker、作用域和命令行筛选。

### 3. HTTP 与 API 测试

学习 HTTP 方法、状态码、请求头、JSON、鉴权、幂等性、分页、错误响应和契约断言。不要只断言 `status_code == 200`。

### 4. Playwright 与 POM

学习稳定定位器、自动等待、web-first assertion、页面对象、浏览器上下文、失败截图和 trace。优先使用角色、标签、测试 ID 定位，少依赖脆弱 XPath。

### 5. SQL 与数据校验

学习 SELECT、JOIN、GROUP BY、聚合、索引基础和事务。测试接口时，要能说明什么时候验证数据库持久化，什么时候只验证 API 契约。

### 6. CI/CD 与质量门禁

学习 Git 分支、Pull Request、GitHub Actions、测试报告、失败产物和环境变量。把冒烟测试放在 PR，把更大范围回归作为手动 workflow。

## 后续练习

- 增加结账字段校验、锁定用户和退出登录场景。
- 增加 API schema、分页和资源关联测试。
- 为失败用例补充缺陷报告，记录复现步骤、期望结果、实际结果和严重程度。
- 创建本地 mock 服务后，再学习性能测试；不要对公共练习站执行压测。
- 后续可选：Appium、Allure、Docker、JMeter/k6 和 AI 辅助用例评审。
